`ContentRendererProps.content` and `DownloadButtonProps.data` are typed `HttpBody` (`string | Record<string, unknown> | unknown[]`, exported from `Models/Http/body`) instead of `any`, so a number or boolean no longer compiles. `DownloadButton`'s `mimeType` no longer defaults to `application/octet-stream`: the data URL's own type is used, else `text/plain` for text and `application/json` for parsed documents. `DownloadButton` is now wrapped in a `div`.
