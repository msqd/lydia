`ContentRenderer` no longer crashes on a binary body that arrives as a parsed object, shows "Empty body" for an empty one, and previews a PDF only for the exact `application/pdf` media type and a `data:application/pdf` URL, in a frame that sends no referrer. The `Content-Disposition` filename is parsed in linear time and now handles `filename*` (RFC 5987) and escaped quotes; control characters and path separators are stripped. `DownloadButton` decodes any data URL (base64 or percent-encoded, commas in the payload), keeps its media type, releases the object URL after a delay, and shows a failure as an alert under the button instead of throwing.
