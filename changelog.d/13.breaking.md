`PerformanceData` loses `highlightingTime` and `formattingTime`, and `PerformanceMetrics` no longer displays timings: they measured the time since mount, not the work done. `tokenStyles` leaves `syntaxTheme`, and `SyntaxHighlighter` drops its `showLineNumbers` prop and renders inline tokens without a wrapper `div` or inline colours: token colours come from `prism.css` alone, which now carries the GitHub light palette `tokenStyles` used and no longer styles `language-*` wrappers. `useCodeHighlighting(content, language)` returns `{ formattedContent, lines, highlightLine }` instead of `{ formattedContent, highlightedAST, isHighlighted }` and takes no options, and `VirtualizedCodeView` takes `lines` and `highlightLine` instead of `content` and `highlightedAST`. `useVirtualization` no longer returns `containerRef`.
