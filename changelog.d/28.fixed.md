Chart tooltips HTML-escape every name and value they interpolate, so a captured request path used as a tooltip name no longer injects markup. `TransactionsListPage` and `TransactionMetadata` no longer throw on a request target that is not a valid URL, such as `//[x`, and show the path and query as captured instead of the parser-normalised form. `splitRequestTarget` is exported from `@msqd/lydia/Models`.
