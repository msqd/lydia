Domain types are closed and `Models` imports nothing from `Components`. `Transaction` and `DetailedTransaction` lose their index signature, so `transaction.anyField` no longer compiles: a consumer that indexes them extends the type (`interface MyRow extends Transaction { extra: string }`) or reads through a cast. `DataTable` takes `TRow extends object` and `types: Record<string, Column<TRow, unknown>>`, and `Column.format` is a method, so a `Column<TRow, number>` still fits. `HttpMessage.body` is `HttpBody` instead of `any`. `BooleanFlagsFilter` and the `"booleanflags"` facet type are removed. `FilterChangeHandler` defaults to `FilterValue` instead of `any`; `Models/Filters` exports `readArray`, `readRange`, `readDates` and `readSingle`, which return a validated value or an empty one, to read a filter value instead of casting it. `FacetOption` lives in `Models/Filters` and `BadgeColor` is no longer imported by `Models/System`, whose status colors are typed `StatusTone`; the old `Components` export paths remain. `SyntaxHighlighter`'s `ast`, `VirtualizedCodeView`'s `highlightedAST` and `useCodeHighlighting`'s result are typed from refractor's tree (`SyntaxTree`) instead of `any`.
