# Architecture decision records

An ADR records a decision that outlives its ticket. It merges with the code that implements it.

## Status

Each ADR carries a status on its second line, after its date.

| Status | Meaning |
| --- | --- |
| proposed | Written, not yet agreed. |
| accepted | Agreed and in force. A release may follow in parentheses, as `accepted (0.3.0)`. |
| superseded | Replaced by a later ADR, which it names. |
